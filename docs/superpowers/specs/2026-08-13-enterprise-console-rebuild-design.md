# 企业控制台彻底重构设计

## 1. 背景与目标

当前 Web 根页面仍由 `common/websocket/static` 下的旧 AIG 编译产物提供。仓库没有对应的可维护前端源码，因此无法在旧页面上可靠完成企业平台化、角色化交互和长期迭代。

本设计新增独立、可维护的企业控制台，并在首批完整验收后一次性替换 Web 根页面。最终发布物不再包含或公开旧 AIG 页面、旧 AIG JavaScript/CSS、`/legacy` 路由或其他浏览器回退入口。现有 Go/Python 扫描引擎、受控 Agent、平台 API 和必要内部协议继续保留。

首批目标不是视觉样板，而是可用于日常工作的完整主流程：身份与改密、安全总览、任务、报告、模型、知识库、用户与角色、审计和品牌设置均接入真实平台 API。

## 2. 已确认产品决策

- 采用“独立构建、整体验收、一次切换”，不按路由逐页混合新旧页面。
- 新控制台直接占据根路径；旧 AIG 页面彻底废弃，不提供 `/legacy`。
- 默认产品名为可配置的“AI 安全治理平台”，不得复用 AIG 或 Tencent 品牌视觉。
- 首批仅支持简体中文，不提供英文切换，也不引入英文资源包或完整 i18n 框架。
- 默认浅色，同时提供同构的深色主题；主题切换只改变设计令牌，不改变布局和信息结构。
- 知识库能力按旧 AIG 实际交互迁移，不扩大旧页面未提供的能力。
- 首批必须接入真实 API，禁止以静态假数据或浏览器本地状态冒充业务闭环。

## 3. 工程架构与切换边界

### 3.1 前端工程

新增 `web/console`：

- React + TypeScript + Vite；
- 使用 pnpm 锁定依赖；
- 企业后台基础组件使用 Fluent UI React v9；
- 复杂图表、YAML/JSON 编辑器按需引入，避免为了少量页面加载整套大型依赖；
- Vitest + Testing Library 承担组件和路由单测；
- Playwright 承担真实浏览器主流程验收；
- 前端构建、测试和依赖安装均使用固定 Node 容器，不要求宿主机安装 Node/pnpm。

前端生产构建输出到 Go 静态资源目录，由现有 Web 服务使用 `go:embed` 提供 SPA 和静态资源。生产环境不新增 Node 常驻服务。

### 3.2 开发与切换

开发期间，新控制台源码和构建输出与旧静态产物隔离，避免未完成页面污染当前可运行演示环境。切换前必须完成：

1. 前端单元测试；
2. API 契约验证；
3. Playwright 主流程；
4. Go 静态资源嵌入构建；
5. 新根页面浏览器请求扫描；
6. 根路径、深链路、刷新和 404/403 行为验证。

通过后，构建产物一次性替换 `common/websocket/static`。最终发布物必须满足：

- `/` 和所有 SPA 深链路只返回新控制台；
- 不包含旧 AIG JS/CSS 和旧 AIG HTML；
- 不提供 `/legacy` 或其他旧 UI 路由；
- 浏览器不调用已退役任务 API，也不连接内部 Agent WebSocket；
- 回滚依靠完整镜像/发行版本回滚，不在同一版本内保留旧页面旁路。

### 3.3 实施切片

实施计划按可独立验证的切片推进，但不做新旧页面混合发布：

1. 先补会话主体、公共品牌、总览和安全分页等后端契约；
2. 建立前端壳层、身份守卫、主题与通用 API/权限组件；
3. 接入任务、附件、报告和模型主流程；
4. 接入知识库、用户、审计、品牌、系统状态和关于页；
5. 完成全量 E2E、安全回归、静态资产清退和一次性根路径切换。

每个切片都必须通过本领域测试。只有第 5 步验收完成后，新控制台才替换生产根页面。

## 4. 应用架构

### 4.1 前端领域边界

前端按领域拆分：

- `app`：入口、路由、错误边界和应用提供器；
- `auth`：登录、会话、首次改密、个人资料；
- `dashboard`：安全评分、趋势、风险分布和最近任务；
- `tasks`：创建、列表、详情、状态、取消和附件；
- `reports`：列表、详情、趋势和 PDF 导出；
- `models`：全局模型与本人私有模型；
- `knowledge`：指纹、漏洞、评测集、MCP、Prompt 集合和 Agent 配置；
- `admin`：用户、角色、密码重置、审计与品牌；
- `shared`：API 客户端、DTO、权限门、设计令牌、表格、表单、反馈和通用状态。

每个领域只消费明确 DTO 和领域服务，不直接依赖后端持久化实体。共享模块不反向依赖业务页面。

### 4.2 页面动作与后端能力契约

下表是首批交付的权威能力清单。“现有”表示当前路由及安全语义可直接复用；“调整”表示路由存在，但必须先补齐安全 DTO、分页或角色语义；“新增”表示后端尚无该能力，必须与前端一起交付。任何标为“调整”或“新增”的能力未完成前，对应页面不得用假数据、本地拼装或旧 `/api/v1/app/**` 接口代替。

| 页面/动作 | API | 状态 | 首批契约与约束 |
| --- | --- | --- | --- |
| 登录前 CSRF 初始化 | `GET /api/v1/auth/csrf` | 新增 | 生成匿名双提交 CSRF Cookie 并返回同值 Token；不创建会话、不接收用户名密码，响应禁止缓存 |
| 登录 | `POST /api/v1/auth/login` | 调整 | 必须校验初始化得到的 CSRF Cookie + Header；成功后轮换 CSRF Token 并签发 Cookie 会话；若需改密只能进入改密流程 |
| 密码重置确认 | `POST /api/v1/auth/password-resets/confirm` | 调整 | 使用匿名 CSRF 初始化 Token；重置令牌和临时密码只放请求体，不放 URL/浏览器存储；成功后回登录页，不直接创建会话 |
| 退出、改密 | `POST /api/v1/auth/logout`、`POST /api/v1/auth/change-password` | 现有 | 使用登录后轮换的 CSRF Token；退出/改密后清理或失效会话材料 |
| 恢复当前主体 | `GET /api/v1/auth/me` | 新增 | 返回稳定的 `id`、`username`、`role`、`must_change_password`；身份不得来自浏览器自报 Header |
| 登录前品牌摘要 | `GET /api/v1/public/brand` | 新增 | 仅返回产品名、主色和安全 Logo 表示；不得返回水印、`updated_by`、内部记录或原始存储信息 |
| 安全总览 | `GET /api/v1/platform/dashboard` | 新增 | 返回服务端按 Subject 限定的评分、30 日趋势、风险分布、最近任务和待关注项；浏览器不读取原始结果重算 |
| 任务列表 | `GET /api/v1/platform/tasks` | 调整 | 改为安全摘要分页 `{items,total,page,page_size}`；普通用户查询本人，管理员/审计员查询全局；不返回原始参数中的凭据 |
| 创建任务 | `POST /api/v1/platform/tasks` | 现有 | 客户端生成并在同一次逻辑提交重试时复用 `Idempotency-Key`；只传模型 ID 和 opaque 附件 ID，不传模型密钥 |
| 任务详情、取消 | `GET /api/v1/platform/tasks/:id`、`POST .../:id/cancel` | 调整 | 普通用户跨 owner 统一 `404`；详情短轮询且 GET 纯读；取消不确定时先读取状态，不自动重复提交 |
| 原始任务结果 HTTP | 当前 `GET /api/v1/platform/tasks/:id/result` | 调整为退出浏览器契约 | 新控制台不调用；匿名请求仍为 `401`，完成身份与改密守卫后的请求统一 `410`；可信服务内部仍可经 `EngineAdapter` 读取并生成不可变脱敏报告 |
| 附件上传、分片、合并、下载 | `/api/v1/platform/tasks/attachments/**` | 现有并调整权限 | 只使用 opaque ID；普通用户仅本人；审计员不得下载；管理员跨 owner 下载在持久化脱敏审计 P0 完成前禁用 |
| 报告列表 | `GET /api/v1/platform/reports` | 调整 | 统一为安全摘要分页 `{items,total,page,page_size}`；不返回 `raw_result`、内部 `render_data`、Logo 字节或所有者内部字段 |
| 报告趋势、详情、PDF | `GET /api/v1/platform/reports/trends`、`GET .../:id`、`POST .../:id/exports/pdf` | 现有 | 详情与 PDF 只消费同一不可变快照；导出写审计并带 CSRF |
| 报告补建 | `POST /api/v1/platform/admin/reports/backfill` | 现有 | 仅管理员；输入只有任务 ID；不得接收浏览器提供的原始扫描结果 |
| 模型目录 | `GET /api/v1/platform/models` | 调整 | 返回带 `source=platform|yaml`、`read_only` 的安全目录；合并只读 YAML 模型且防同名遮蔽；Token 始终掩码 |
| 模型创建、更新、删除、轮换 | `/api/v1/platform/models/**` | 现有 | 用户只写本人私有模型，管理员只写全局模型，审计员只读；YAML 模型永不可写 |
| 指纹、漏洞、评测、MCP、Agent 配置 | `/api/v1/knowledge/**` | 现有 | 领域适配器兼容现有 `{status,message,data}`；读取全角色可用；治理写操作仅管理员并带 CSRF、审计 |
| Prompt 集合 | `GET /api/v1/knowledge/prompt_collections` | 现有读取、调整写路由 | 全角色只读；现有 Prompt 创建、编辑、删除路由退出浏览器公开契约，首批不显示写入口 |
| 用户与角色 | `/api/v1/platform/admin/users/**` | 现有并调整列表 | 列表补安全分页；创建、禁用、角色修改、密码重置仅管理员；不回传密码或会话材料 |
| 审计查询、完成与恢复 | `/api/v1/platform/admin/audit-events/**` | 现有并调整列表 | 查询补稳定分页/游标；审计员只读，管理员可执行已有完成/恢复动作；详情不得回显敏感元数据 |
| 品牌读取与更新 | `GET/PUT /api/v1/platform/brand` | 现有 | 登录后全角色可读；仅管理员更新；Logo 仍受后端 MIME、尺寸和像素限制 |
| 数据同步与版本状态 | `/api/v1/system/update-data`、`/api/v1/system/version` | 现有 | 管理员触发同步；管理员/审计员查看状态；普通用户不可见 |
| 关于 | `GET /api/v1/version` + 随前端发布的归属清单 | 调整 | 版本端点改为安全白名单 DTO（版本、提交标识、构建时间），提交标识和时间由构建参数注入；显示配置产品名、上游归属和第三方声明；不加载旧 `aigdocs`、原始文件内容或公网内容 |

平台新建或调整后的响应必须使用稳定的前端 DTO，不能直接序列化数据库实体。平台领域错误由 API 客户端统一规范为 `code`、中文 `message`、可选字段错误和 HTTP 状态；知识库兼容接口保留原响应格式，由 `knowledge` 领域适配器转换。前端组件不得自行判断两套响应格式。

## 5. 身份、会话与数据流

应用启动顺序：

1. 通过 `GET /api/v1/auth/me` 读取服务端会话主体；
2. 未登录进入登录页；
3. 需要首次改密或管理员重置密码后，强制进入改密页；
4. 登录页先读取公共安全品牌摘要，登录后再读取受保护品牌配置；
5. 按服务端 Subject 生成可见导航；
6. 进入当前角色默认首页。

所有请求同源访问 `/api/v1/**`。身份仅来自 HttpOnly 会话 Cookie。登录和密码重置确认页先调用匿名 CSRF 初始化端点，登录成功后服务端轮换 Token；所有浏览器写请求统一附带双提交 CSRF Token。前端显示控制不能替代服务端授权。

浏览器存储约束：

- 禁止在 `localStorage`、`sessionStorage` 或 URL 中保存会话、密码、模型 Token、附件路径、原始扫描结果和其他敏感业务数据；
- 仅允许保存主题偏好；
- 页面刷新后从服务端恢复任务、报告和用户状态。

统一响应处理：

- `401`：清理内存态并进入登录；
- 首次改密状态：进入强制改密页面；
- `403`：保留当前上下文并显示新控制台无权限页；
- `404`：普通用户跨所有者资源使用不存在语义，不提供资源存在性提示；
- 网络失败和 `5xx`：展示可重试状态，不自动重复业务写入。

## 6. 信息架构与角色导航

### 6.1 导航结构

- 登录和强制改密不进入主框架；
- 所有已登录角色显示安全总览、扫描任务、风险报告、模型资产、规则与知识库；
- 管理员额外显示用户与角色、审计记录、品牌设置和系统数据治理；
- 审计员额外显示全局审计和只读系统状态；
- 个人中心、关于和主题切换放在顶栏账户区；个人中心首批只显示当前主体并提供改密和退出，不提供尚无后端能力的资料编辑；
- 首批不建设帮助中心，也不迁移旧 `aigdocs`。技术 API 文档继续由独立 Swagger 地址提供，不作为业务控制台导航。

控制台不设置营销首页。未知路由使用新 404 页面，无权限路由使用新 403 页面，不回退旧 AIG。

### 6.2 角色边界

普通用户：

- 管理本人任务、本人附件、本人报告和私有模型；
- 使用管理员提供的全局模型；
- 只读查看规则和知识数据；
- 不能看到其他用户私有资源和治理入口。

安全审计员：

- 全局只读查看任务、脱敏报告、趋势和审计；
- 可导出受授权报告；
- 不显示新建、取消、编辑、删除、补建或配置入口；
- 不显示或调用原始附件下载；
- GET 不得触发隐藏业务写入。

管理员：

- 管理用户、角色、密码重置、全局模型、品牌和知识数据；
- 全局查看任务、报告和审计；
- 跨所有者附件下载只有在后端完成持久化审计 P0 后才开放，否则前端保持禁用。

### 6.3 权威角色 × 动作矩阵

| 资源/动作 | 管理员 | 普通用户 | 安全审计员 |
| --- | --- | --- | --- |
| 总览 | 全局 | 本人 | 全局只读 |
| 任务列表/详情 | 全局 | 仅本人 | 全局只读 |
| 原始任务结果 HTTP | 禁止，改看脱敏报告 | 禁止，改看本人脱敏报告 | 禁止，改看脱敏报告 |
| 创建任务 | 以本人身份创建 | 以本人身份创建 | 禁止 |
| 取消任务 | 可治理取消任意非终态任务 | 仅本人非终态任务 | 禁止 |
| 附件上传/绑定 | 仅本人创建的任务 | 仅本人任务 | 禁止 |
| 附件下载 | 本人；跨 owner 待审计 P0 后开放 | 仅本人 | 禁止，不存在授权或分享旁路 |
| 报告列表/详情/PDF | 全局读与导出 | 仅本人读与导出 | 全局脱敏读与导出 |
| 报告补建 | 允许 | 禁止 | 禁止 |
| 平台模型读取 | 全部平台模型 + YAML | 全局 + 本人私有 + YAML | 全局 + YAML，只读 |
| 平台模型写入 | 仅全局模型 | 仅本人私有模型 | 禁止 |
| 指纹/漏洞/评测/MCP/Agent 配置 | 读取、创建、编辑、删除 | 只读 | 只读 |
| Prompt 集合 | 只读 | 只读 | 只读 |
| Agent 连通性/Prompt 测试 | 允许 | 禁止 | 禁止 |
| 用户、角色、密码重置 | 允许 | 禁止 | 禁止 |
| 审计 | 全局读；允许治理完成/恢复 | 不显示 | 全局只读 |
| 品牌 | 读取、更新 | 只读 | 只读 |
| 数据同步 | 触发并查看状态 | 不显示 | 只读状态 |
| 个人中心/关于/主题 | 可用 | 可用 | 可用 |

矩阵是前后端共同验收标准：菜单、路由、按钮、请求和服务端策略必须一致。前端隐藏不构成授权；任何角色差异都必须有服务端测试。普通用户跨 owner 的任务、报告和模型详情统一使用 `404` 语义；审计员对附件一律拒绝。

## 7. 首批页面范围

### 7.1 身份与个人

- 登录页；
- 密码重置确认页：仅提交重置令牌和临时密码，不把令牌写入 URL 或浏览器存储；
- 首次/重置后改密页；
- 个人资料与退出；
- 关于页：显示配置产品名、版本/构建信息、上游项目归属和第三方声明；
- 新 403、404 和全局错误页。

### 7.2 安全总览

总览只聚合服务端不可变报告快照和安全任务摘要，不读取或解析原始引擎结果。统计窗口为“含当前 UTC 日期在内的最近 30 个 UTC 自然日”：下界是当前 UTC 日零点向前 29 日，结束时间是请求时刻。

数据范围：

- 普通用户只统计 `owner_user_id` 等于当前 Subject 的快照和任务；
- 管理员与安全审计员统计全局数据；
- 只有完成时间落入窗口且报告快照有效的任务参与评分、风险分布和趋势；取消、失败、运行中及缺快照任务不参与这些指标，但可出现在最近任务中。

指标定义：

- `security_score` 是窗口内所有有效快照已固化 `risk.score` 的算术平均值，四舍五入为整数；不得在浏览器重算，也不得根据当前规则改写历史快照；
- 响应返回实际出现的 `mapping_versions`。不同映射版本仍使用各自快照已固化分数参与平均，界面明确标为“快照平均安全分”并在版本混合时显示说明；
- 高、中、低风险分布分别对快照中已固化的三个计数求和；
- 趋势固定返回 30 个按日期升序的 UTC 桶，每桶包含完成报告数、平均安全分和高/中/低计数；无报告的日期补零，平均分为 `null`；
- 最近任务不受 30 日窗口限制，按 `updated_at DESC, id DESC` 取安全摘要前 5 条；
- 待关注项只取窗口内 `high > 0` 或 `score < 60` 的快照，按 `high DESC, score ASC, completed_at DESC, report_id DESC` 排序，最多 5 条，只返回报告 ID、任务 ID、任务类型、完成时间、分数和风险计数。

空数据时返回 `has_data=false`、`security_score=null`、风险计数全零、30 个补零趋势桶和空待关注列表；界面显示“暂无已完成报告”，绝不把无数据展示成 100 分。`GET /api/v1/platform/dashboard` 一次返回上述快照聚合和最近任务摘要，所有角色过滤、窗口、排序和上限均由服务端执行并有数据库与 API 契约测试。

### 7.3 扫描任务

- 分页列表、筛选和状态；
- 分步创建：任务类型 → 模型与参数 → 附件 → 确认；
- 详情、受保护短轮询、最后更新时间和重试提示；
- 取消；
- opaque 附件完整上传、分片上传和受授权下载；
- `pending`、`dispatching`、`dispatch_unknown`、`running`、`succeeded`、`failed`、`cancelled` 全部使用真实语义。

创建任务时由客户端生成幂等键。同一提交的网络重试必须复用该键，不得自动创建第二个任务。提交成功后进入任务详情。

### 7.4 风险报告

- 安全摘要列表与分页；
- 报告详情、评分说明、趋势、风险分布、Top 风险、建议、覆盖、结论和技术发现；
- PDF 导出和明确的导出错误；
- 在线页面与 PDF 只消费同一不可变快照；
- 页面不获取或渲染原始引擎结果、模型凭据、附件路径和当前可变品牌对象。

### 7.5 模型资产

- 普通用户管理本人私有模型；
- 管理员管理全局模型；
- 模型 Token 仅在创建或明确替换时输入；
- 读取、列表和编辑回显始终为掩码；
- YAML 内置模型只读显示，不能被同名数据库模型遮蔽；
- 禁用和删除使用明确确认。

### 7.6 核心管理后台

- 用户创建、禁用、角色修改和密码重置；
- 审计列表、筛选和详情；
- 品牌名称、Logo、主色与水印配置；
- 数据目录同步状态、手动同步和版本状态；
- 权限菜单由服务端 Subject 驱动；
- 写按钮对无权角色不可见，但服务端仍执行最终授权。

## 8. 规则与知识库迁移

知识数据位于运行时 `data/` 文件目录，不嵌入 Go 代码。新控制台保持旧 AIG 页面实际提供的编辑范式：

| 数据类型 | 首批交互 | 角色 |
| --- | --- | --- |
| 指纹规则 | 列表/搜索/详情；上传 YAML 新建；YAML 原文编辑；样例下载；删除 | 全角色只读，管理员写 |
| 漏洞规则 | 列表/搜索/详情；上传 YAML 新建；YAML 原文编辑；样例下载；删除 | 全角色只读，管理员写 |
| 评测集 | 列表/详情；上传 JSON 新建；JSON 原文编辑；当前数据下载；删除 | 全角色只读，管理员写 |
| MCP 插件 | 列表/详情；上传 YAML 新建；YAML 原文编辑；当前数据下载；删除 | 全角色只读，管理员写 |
| Prompt 集合 | 浏览、筛选和详情 | 全角色只读；首批不新增旧页面不存在的编辑能力 |
| Agent 配置 | 动态结构化表单、高级设置、YAML 导入、模板下载、连通性测试和 Prompt 测试 | 管理员写，其他角色只读 |

原文编辑器提供行号、YAML/JSON 高亮、格式校验、错误定位和文件导入，但不改变旧文件 schema。保存前展示资源名称和影响提示；删除、覆盖和远端同步使用二次确认。首批不新增审批流、版本仓库或自动回滚。

知识写操作继续使用现有管理员权限、CSRF、受治理 API 和持久化审计，前端校验不是最终安全边界。

## 9. 视觉与主题系统

### 9.1 视觉方向

采用已确认的“监管台账式”：

- 浅色侧栏、冷灰工作区、白色内容卡片；
- 钴蓝作为主色和趋势线颜色；
- 通过细边界、留白、淡蓝选中态和左侧细强调线建立层级；
- 高信息密度但避免拥挤；
- 风险红/橙/蓝只表达风险等级，不用作大面积品牌色；
- 不复用旧 AIG/Tencent Logo、布局或装饰语言。

### 9.2 浅色与深色

- 默认浅色；
- 顶栏提供主题切换；
- 深色使用深蓝灰而非纯黑；
- 两种主题布局和组件完全同构，仅使用不同设计令牌；
- 可选择浅色、深色或跟随系统；
- 主题偏好可本地保存，不包含任何敏感数据。

### 9.3 品牌与字体

- 产品名、Logo、主色和水印从服务端品牌配置读取；
- 品牌后端默认值同步调整为“AI 安全治理平台”；加载失败也回退到该名称和独立默认几何标识；
- 中文正文使用随镜像离线分发且许可明确的中文无衬线字体；
- 数字和英文指标可使用许可明确的 IBM Plex Sans；
- 不使用公网字体/CDN，也不使用许可不明确的旧字体。

### 9.4 交互与可访问性

- 8px 间距网格和紧凑企业表格；
- 宽屏优先，最低支持 1280px 工作区并提供基本平板适配；
- 加载、空数据、无权限、网络失败和首次配置缺失有独立状态；
- 页面、菜单和状态动效约 120–180ms；
- 遵循减少动态效果设置；
- 所有交互支持键盘、可见焦点、语义标签和企业后台所需对比度。

首批只提供简体中文。API 内部标识和扫描器英文常量应映射为中文界面文案，不直接显示程序字段名。

## 10. 错误处理与防泄漏

- API 客户端区分字段错误、业务错误、权限错误、网络错误和服务不可用；
- 写操作按钮在提交期间禁用，防止重复点击；
- 对不确定结果先读取服务端状态，不自动重复写入；
- 错误、通知、埋点和浏览器日志不输出 Token、Cookie、原始结果、附件路径或知识文件中的凭据；
- YAML/JSON 校验错误只显示必要行列和泛化原因；
- 模型 Token 输入框默认不回填，掩码值不作为新 Token 提交；
- 文件上传只向后端提交文件内容和受支持元数据，不构造或显示服务端路径。

## 11. 测试与验收

### 11.1 单元与组件测试

- 会话和首次改密路由守卫；
- 三角色菜单、按钮和 403；
- 浅色/深色主题及品牌回退；
- 任务幂等键和写入防重复；
- 模型掩码与替换逻辑；
- YAML/JSON 编辑、校验和危险操作确认；
- API 错误映射；
- 响应中敏感字段不渲染。
- 新增/调整端点的安全 DTO、分页 envelope、角色过滤和错误 envelope；
- 知识库兼容响应只在领域适配器中转换，不渗透到页面组件。

### 11.2 浏览器端到端测试

使用隔离 PostgreSQL 和测试专用平台：

1. 管理员登录、首次改密、创建用户和角色；
2. 普通用户登录、配置私有模型、上传附件和创建扫描；
3. 任务详情短轮询、取消和终态；
4. 报告列表、详情和 PDF；
5. 管理员编辑指纹/漏洞/MCP/评测集，Agent 配置测试；
6. 审计记录出现相应治理动作；
7. 审计员全局只读，无写按钮和附件下载；
8. 越权、CSRF、首次改密和匿名请求正确拒绝。

### 11.3 切换验收

- `/`、深链路和刷新只加载新控制台；
- 浏览器请求中无旧 AIG JS/CSS、旧任务 API、Agent WebSocket 和 `/legacy`；
- 生产构建产物可被 Go `embed` 编译；
- 浅色、深色、1280px 和常用宽屏通过视觉验收；
- 键盘焦点、空状态、错误状态和长中文内容可用；
- 前端资产全部离线可用，不访问公共 CDN；
- 首批范围的所有页面均接真实 API，不依赖旧页面补功能。

## 12. 非目标

- 不重写扫描器、规则格式、检测算法和任务协议；
- 不保留旧 AIG 浏览器页面或兼容入口；
- 不实现英文界面或多语言框架；
- 不新增营销站点、开放注册、SSO、多租户或组织树；
- 不为知识库新增审批流、版本库和自动回滚；
- 不新增旧 Prompt 集合页面原本不存在的写入口；
- 不在生产部署中新增独立前端服务。

## 13. 首批完成定义

以下条件必须同时满足，才允许声称“前端重构首批完成”并替换旧页面：

1. 新控制台源码可维护、可测试、可容器化构建；
2. 身份、总览、任务、报告、模型、核心后台、审计、品牌和本设计规定的知识库能力全部接入真实 API；
3. 三角色和首次改密主流程通过 E2E；
4. 主题、品牌、简体中文、错误状态和可访问性达到验收要求；
5. 旧 AIG 页面、资源和浏览器路由从发布产物移除；
6. 安全、敏感信息、CSRF、幂等和附件权限回归通过；
7. Go/Docker 构建、静态资源嵌入和离线运行验证通过。
