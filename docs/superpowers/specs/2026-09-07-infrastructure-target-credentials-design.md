# 基础设施目标访问凭据

后续更新：用户已明确要求内网 HTTP 支持。本文原 HTTPS-only 范围由 [HTTP 显式许可设计](2026-09-07-target-credentials-http-design.md) 扩展；其余凭据保护和同源边界保持。

用户已确认现在实施此前讨论的独立凭据管理、扫描任务引用和执行时认证。沿用控制台设计与身份治理，不改四类扫描的分工。

## 方案

直接把认证 Header 写入任务最简单，但会把密钥带入任务存储；借用模型或 MCP 配置会混淆目标和调用模型的权限。采用独立凭据资源，任务只保存 ID 与版本，执行前才解密。已有模型主密钥管理继续负责密钥轮换，使用独立的凭据 AAD 域绑定资源、所有者、目标和版本。

## 用户行为

- “凭证配置”下新增“基础设施凭据”。普通用户和管理员管理自己的私有凭据；审计员不可使用或读取此资源。
- 列表显示名称、目标源、认证类型、启用状态、版本；新建、编辑、替换密钥、停用、删除可用。任何读取接口不返回认证明文，编辑时留空保留原值。
- 认证方式为 bearer、api_key、basic、cookie。API Key 指定请求头名；Basic 的用户名和密码一起加密。禁止 Host、代理、跳转、连接控制等头；禁止换行和控制字符。
- 一个凭据绑定一个 HTTPS 源（协议、主机、有效端口），不接受路径（根路径允许）、查询、片段或 URL 用户信息。客户端不能放宽证书验证。
- AI 基础设施扫描选择可选凭据。带凭据时仅接受手动填写的、与其源完全匹配的明确 HTTPS URL，可多个路径；不接受附件或端口发现表达式。没有选择凭据的任务继续现有行为。
- UI 清楚提示目标范围及 HTTPS 要求，禁用凭据保留在管理列表但不进入任务选择。已选凭据失效时保留选择并阻止提交，直到用户明确重选或选择匿名扫描。

## 接口和状态

基础地址 `/api/v1/platform/target-credentials`。GET 返回 `{items: [...]}`；POST 创建；PUT `/:id` 更新；DELETE `/:id` 删除。写入受现有身份、角色、CSRF 和治理审计保护；PUT/DELETE 要求 `If-Match: <revision>`，冲突返回 409。所有者条件参与写入查询，避免跨用户操作。

安全视图字段：`id,name,origin,auth_type,header_name,disabled,revision,created_at,updated_at`。创建输入：`name,origin,auth_type,header_name?,username?,secret`；更新同样结构（空 secret 保留）并带 `disabled`。变更 origin/auth_type/header_name 必须同时提交新 secret；避免旧权限被重新绑定到新目标。

任务参数增加成对的 `target_credential_id` 与 `target_credential_revision`。创建时验证所有者、版本、启用状态与目标；已有相同幂等请求先返回原任务。下发前重新验证，停用、删除或修改后的未下发任务不能继续使用旧配置。变更不召回已发出的请求。

运行时字段 `target_auth` 含 `{credential_id,revision,origin,headers}`，只能进入 Agent assignment 内存通道。任务参数、引擎 session、浏览器 DTO、审计、报告不存这些 headers。恢复、失败和无 Agent 路径不能回退成匿名扫描。

## 请求隔离与脱敏

在 HTTP 传输末端注入 headers，只允许同源 HTTPS 请求并验证服务器证书；拒绝 Host 覆盖，禁止不受控 raw HTTP / HTTP2 绕过。跨源、协议降级、跨端口跳转不会发出请求；同源跳转仍需重新执行范围校验。扫描规则内构造的其他地址也不能携带认证。原始模板下载、模型请求和平台 API 不使用目标凭据。

认证值只能存在于传输副本，扫描调用方持有的 Request 不含密钥。HTTP 响应进入指纹、漏洞证据、LLM 或日志之前，清除 Cookie 响应头并替换认证值（包括 Bearer token、Basic 编码/密码、Cookie 各值的反射）。对运行中的凭据任务再做服务端事件脱敏；没有相应脱敏上下文时拒绝接收这类任务事件，避免重启后不安全接收。错误采用固定消息，不能包含目标响应原文或认证值。

认证扫描从随 Agent 发布的本地 data/fingerprints 与 data/vuln（英语使用 vuln_en）读取规则，可由 AIG_DATA_DIR 明确指定受控规则根目录。缺失、空库或格式错误返回初始化失败，不转用浏览器知识库会话。规则更新需同步发布到 Agent。认证主请求遇到 TLS、网络、作用域错误或 401/403 时，任务返回失败并等待已启动分析结束，不生成成功报告。认证扫描不调用 Chromium 截图或视觉分析，避免页面导航与子资源请求绕过 HTTP 目标范围及脱敏控制；保留认证 HTTP 证据和可选文本模型分析。认证后可访问不能单独证明未授权访问漏洞。
